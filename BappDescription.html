SquidSec AI Bridge exposes a loopback MCP and JSON HTTP API so an LLM agent can use the live Burp project: scope, proxy history, send, Repeater, Intruder, sitemap, Scanner issues, Collaborator, Organizer, WebSockets, cookies, and engagement helpers (curl, finding drafts, CSRF PoC).

The listener binds to 127.0.0.1 by default and requires a bearer token for mutating calls. Tool discovery is GET /mcp/tools. Scanner and Collaborator features need Burp Suite Professional and fail cleanly on Community Edition.

Do not point the listener at untrusted networks. Treat HTTP message content as untrusted. Generated findings redact common secret headers.
