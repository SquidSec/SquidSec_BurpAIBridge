SquidSec AI Bridge is a local MCP and JSON HTTP API for Burp Suite. An authorized LLM agent can discover tools (GET /mcp/tools) and drive the live project: scope, proxy history, send, Repeater, Intruder, sitemap, Organizer, WebSockets, cookies, Scanner (Pro), and Collaborator (Pro).

The listener binds to 127.0.0.1 by default and requires a bearer token for project data. It does not call an LLM, Burp AI, or any third-party AI API. Scanner and Collaborator features need Burp Suite Professional and fail cleanly on Community Edition.

Do not expose the listener to untrusted networks. Treat HTTP message content as untrusted. Generated findings redact common secret headers.
